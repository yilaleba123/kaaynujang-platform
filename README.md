# 🎓 KAAYNUJÀNG - Plateforme E-Learning

> **Projet Full Stack Python / Angular - Programme de Mentorat Force-N 2026**

KAAYNUJÀNG est une plateforme de formation en ligne interactive (cours, quiz, suivi de progression, certificats et forum) destinée à favoriser l'accès à la formation numérique au Sénégal et en Afrique.

---

## 🛠 Stack Technique

- **Backend :** Python 3.12, Django, Django REST Framework
- **Frontend :** Angular 17+, SCSS, RxJS
- **Base de Données :** PostgreSQL (Supabase)
- **Authentification & Sécurité :** JWT, Contrôle d'Accès par Rôle (RBAC)
- **Gestion de version :** Git & GitHub

---

## 📂 Structure du Dépôt

- `backend/` : API REST Django et logique métier.
- `frontend/` : Interface utilisateur Angular.
- `database/` : Scripts de création de schémas PostgreSQL et jeux de données de test.
- `docs/` : Cahier des charges, diagrammes UML et maquettes UI/UX.

---

## 🌿 Stratégie des Branches (GitFlow)

- `main` : Branche de **Production**.
- `staging` : Environnement de **Déploiement & Validation**.
- `develop` : Branche principale de **Développement**.
- `feature/*` : Branches de fonctionnalités individuelles.
